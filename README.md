# Java Basic

个人 Java 基础学习代码仓库，用于记录 Java 学习过程中的示例代码、课堂练习和知识点测试。

## 📚 学习内容

目前主要学习 Java 基础语法，包括：

- Java 基本语法
- 变量与数据类型
- 运算符
  - 算术运算符
  - 自增自减运算符
  - 字符串相关操作
  - 逻辑运算符
  - 三元运算符
- 判断与循环
  - if
  - switch
  - for
  - while
- 数组
  - 静态数组
  - 动态数组
  - 遍历数组
    - 求和
    - 求极值
  - 打乱数组
  - 二维数组
- 方法
  - 定义
  - 带参：形参，实参
  - 返回
  - 重载
- 面向对象

内容会随着学习进度持续更新。
